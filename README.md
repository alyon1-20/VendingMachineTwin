# VendingMachineTwin
Attributes
status: Tracks whether the vending machine is on or off.
balance: Tracks the amount of money inserted.
snack_price: The price of a snack.
snack_stock: The number of snacks available.
total_sales: Tracks the total amount earned from purchases.

Methods
turn_on(): Turns the vending machine on.
turn_off(): Turns the vending machine off.
insert_money(): Adds money to the machine.
buy_snack(): Allows a customer to purchase a snack.
restock(): Adds snacks to the inventory.
display_status(): Displays the current vending machine information.

How to Run
Download the Python file.
Open the file in Visual Studio Code.
Make sure Python is installed.
Run the program using python vending_machine.py.
View the results in the terminal.
